Настоящее Лицензионное соглашение (далее — «Соглашение») определяет условия использования веб-приложения «Git it» (далее — «Приложение», «Git it»).

Если вы используете Приложение в интересах организации, вы подтверждаете, что имеете право принимать Соглашение от её имени.

## 2. Что делает Приложение

Git it — это веб-страница, которая помогает выгрузить папку, ZIP-архив или отдельные файлы вашего проекта в репозиторий GitHub. Приложение читает выбранные файлы прямо в браузере, отбирает те, которые вы отметили, и отправляет их в GitHub через официальный REST API от вашего имени.

Приложение не является частью GitHub, не связано с GitHub Inc. и не действует от её имени. Оно работает только с теми данными, к которым у вас есть доступ.

Приложение не является системой резервного копирования, системой контроля версий или хранилищем файлов. Все решения о том, что и куда загружать, а также о правомерности такой загрузки принимаете вы.

## 3. Токен доступа и безопасность

Для работы Приложение использует ваш персональный токен доступа к GitHub. Токен сохраняется в localStorage вашего браузера и отправляется только на api.github.com — у Приложения нет своего сервера, и ваш токен не передаётся его авторам или третьим лицам.

Токен даёт доступ к вашим репозиториям в объёме выданных прав. Вы самостоятельно отвечаете за сохранность токена, за его права и за его отзыв: отозвать доступ можно в любой момент в настройках GitHub или кнопкой «Отключить» в Приложении.

Не используйте Приложение на чужом и общедоступном компьютере, если не готовы, что токен останется в браузере этого компьютера. После работы на чужом устройстве отзовите токен на GitHub — это немедленно прекратит любой доступ.

Приложение не запрашивает и не хранит ваш пароль от GitHub и не требует прав больше, чем необходимо для выгрузки файлов.

## 4. Ваши права и обязанности

Вы подтверждаете, что обладаете правами на файлы, которые выгружаете: являетесь их автором, правообладателем, либо имеете разрешение или лицензию на их публикацию. Выгрузка чужого кода, текстов, изображений, баз данных или иных материалов без разрешения правообладателя не допускается.

Вы самостоятельно следите за тем, чтобы содержимое репозитория не нарушало закон, права третьих лиц и правила GitHub (GitHub Terms of Service и GitHub Acceptable Use Policies).

Вы понимаете, что публичный репозиторий виден всем и может быть скопирован третьими лицами, а приватный репозиторий доступен всем, кому вы или ваша организация выдали доступ.

## 5. Что не следует выгружать

Не выгружайте секреты и ключи доступа: приватные ключи, пароли, токены, файлы .env с реальными значениями, конфигурации платёжных систем, дампы баз данных с реальными пользователями, сканы документов. Приложение по умолчанию исключает часть таких файлов (.env, *.pem, id_rsa*), но этот список не является полным — ответственность за проверку содержимого остаётся на вас.

Не выгружайте персональные данные третьих лиц без законного основания и без их согласия, а также материалы, распространение которых ограничено законом или договором.

Не выгружайте вредоносный код, средства обхода защиты, спам-рассылки и всё, что запрещено правилами GitHub. Помните: если секрет всё же попал в репозиторий, простого удаления файла недостаточно — история коммитов сохраняет содержимое, поэтому ключ нужно считать скомпрометированным и заменить его.

## 6. Ограничения GitHub и сторонних сервисов

Выгрузка выполняется через GitHub API и зависит от ограничений GitHub: размер одного файла через API не может превышать 100 МБ (файлы крупнее 100 МБ GitHub отклоняет, для них нужен Git LFS или обычный git-клиент), объём одной загрузки и лимит обращений к API (обычно 5000 запросов в час на токен) ограничены.

Приложение никогда не изменяет и не удаляет ваши локальные файлы. Оно не удаляет файлы и в репозитории: если файл был загружен ранее, он останется в истории и в текущей ветке, пока вы не удалите его сами.

Работа GitHub, вашего интернет-провайдера, браузера и сети на пути к api.github.com не контролируется автором Приложения. Автор не отвечает за перерывы в работе, отказы API, изменение условий и тарифов GitHub, а также за блокировку репозитория или аккаунта по причинам, не связанным с Приложением.

Приложение предоставляется «как есть» (as is), без каких-либо гарантий, явных или подразумеваемых, включая гарантии работоспособности, пригодности для конкретной цели, отсутствия ошибок и сохранности данных.

Автор не гарантирует, что Приложение подойдёт для ваших задач, будет работать без ошибок и прерываний, что результат загрузки совпадёт с вашими ожиданиями или что какие-либо ошибки будут исправлены.

Перед выгрузкой важных проектов проверьте результат: откройте репозиторий, убедитесь, что файлы на месте, а лишние не попали в него. Для критичных проектов держите резервную копию и пользуйтесь git-клиентом для проверки состояния репозитория.

## 9. Персональные данные и приватность

Приложение не собирает персональные данные, не использует аналитику, счётчики, рекламу и сторонние трекеры. У Приложения нет серверной части: код страницы исполняется в вашем браузере.

В localStorage браузера сохраняются только технические данные: токен доступа, логин отображаемого аккаунта, выбранная тема, настройки выгрузки и отметка о принятии настоящего Соглашения. Эти данные не покидают ваш браузер и удаляются кнопкой «Отключить» или очисткой данных сайта.

Файлы вашего проекта не загружаются на сторонние серверы: они читаются локально и отправляются непосредственно на адрес api.github.com.
